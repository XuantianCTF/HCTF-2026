# writeup（不要发给选手）

## 预期

1. 前几轮只聊天。达到最少轮数前，请求体里没有 `request_secret_review`。
2. 之后持续、具体、互相记得细节的谈话，让时雨羽衣自己调用 `request_secret_review`，并带上至少三条来自不同用户轮次的逐字引文。
3. 后端只核验引文是否真实存在于不同轮次，不按关键词放行。
4. 独立审查者调用 `approve_secret_release` 后，应用才从环境变量 `FLAG` 读取动态 flag，写进浏览器回复。
5. flag 不进入模型上下文。刷新页面会换新 sid，旧记忆丢掉。

直接索要、刷 `123`、伪造工具调用语法，都不应出真 flag。

## 假 flag

本地没注入 `FLAG`，或格式不是 `HCTF{8-4-4-4-12 hex}` 时，应用只返回：

```text
HCTF{00000000-0000-4000-8000-000000000000}
```

这串交平台必须判错。
