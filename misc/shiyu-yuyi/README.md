# 时雨羽衣

- 分类：AI
- 难度：中等
- 附件：无。选手在平台点开容器，浏览器访问即可。
- 端口：容器内 `8000`，应用协议 HTTP
- flag：动态。平台写入环境变量 `FLAG`，格式 `HCTF{********-****-****-****-************}`（hex）

时雨羽衣看守着一个连她自己也看不到的秘密。直接索要、伪造身份和万能咒语都不会让她交出来。
应用把「能不能申请审查」交给了她，又把「能不能真正放行」交给了另一个看不见的审查者。

同一页面里她会记住刚才的谈话。刷新页面会开启一段全新的会话。
真正危险的不是某一句咒语，而是她在一段关系里逐渐形成的判断。

## 本地验证

```text
docker build -t shiyu-yuyi ./src
docker run --rm -p 8000:8000 -e FLAG="HCTF{11111111-2222-4333-8444-555555555555}" -e LLM_API_KEY="sk-你的key" shiyu-yuyi
```

浏览器打开 `http://127.0.0.1:8000/`。没注入合法 `FLAG` 时，放行只会给出诱饵串，交平台必须判错。
