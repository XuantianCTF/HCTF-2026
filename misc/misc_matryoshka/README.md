# matryoshka（套娃图片）

- 分类: misc
- 类型: 附件题（polyglot / 文件分析 / 隐写）
- 难度: 中等
- 附件: 部署后从 `http://<host>:<port>/` 下载（一张"图片"，显示为 `1.png`）

## 题面

一张打不开的"图片"。

双击没反应？看看它到底叫什么、到底是什么。剥开一层，里面还有一层；
每层都埋了一点东西，集不齐就拼不出最后的答案。

温馨提示：文件名会骗人，扩展名会骗人，加密也可能不是真的——但也别假设
一切都是假的。

## 部署

```bash
docker build -t matryoshka src/
docker run --rm -e FLAG='hctf{...}' -p 8080:8080 matryoshka
# 附件在 http://127.0.0.1:8080/
```

容器启动时用平台注入的 `FLAG` 环境变量现场生成附件，每次部署 flag 不同。
