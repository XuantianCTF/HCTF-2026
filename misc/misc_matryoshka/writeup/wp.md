# matryoshka wp（第一人称解题过程）

## 0. 打不开的"图片"

下载下来一个文件，资源管理器里显示 `1.png`。双击——没反应，让我选打开方式。

第一步当然是看它到底是什么。`file` 一看是 PNG；但先别急，`ls` 一下当前目录，终端里显示的名字和资源管理器里**不一样**：`gnp.1`，前面还有个看不见的字符。十六进制一看，文件名开头是 `E2 80 AE`——U+202E，RIGHT-TO-LEFT OVERRIDE。它强制后面的字符从右往左渲染，所以 `gnp.1` 显示成了 `1.png`，而 Windows 按最后一个 `.` 把扩展名解析成 `.1`，当然没有关联程序。

顺便明白了为什么 `glob("*.png")` 一个都匹配不到。

## 1. 图片还是图片

强制用图片查看器打开，正常显示。十六进制往尾部翻：PNG 的 IEND 之后跟的不是文件结束，而是一段文本和一个 `PK\x03\x04`——图片尾部长了一个 zip。经典 polyglot：图片解码器读到结束标记就停，尾部追加的数据它不看不碰。

图片和 zip 之间的文本：

```
MATRYOSHKA-CIPHER-FRAG 1/5
<16 个 hex 字符>
```

碎片，一共应该有 5 段。

## 2. 第一层 zip：伪加密

解压，弹密码框。是加密吗？先别爆破——看结构。ZIP 每个条目的 local file header（偏移 +6）和 central directory header（偏移 +8）里有个 2 字节的 General Purpose Bit Flag，它的 bit0 是"加密"标志。检查发现两处都被置 1 了，但数据开头没有 ZipCrypto 该有的 12 字节 encryption header 结构特征——**伪加密**，数据其实是明文。把两处 bit0 清零，解压成功。

顺带从解压软件的"注释"栏（archive comment，不解压就能看）读到 `MATRYOSHKA-KEY-FRAG 1/5`。

解压出来一个文件，又是 RLO 假名，显示 `2.gif`（真实 `fig.2`），内容是一大段 hex 文本——decode 之后又是一个 polyglot。套娃开始了。

## 3. 第二层：kipfel 的 gif

这层的尾部没有碎片标记，只有一句：

```
kipfel可爱捏，好看，爱看，多看
```

多看？那就看这个 gif 本身。`exiftool` 没东西，`strings` 也没东西——问题出在图片内部。GIF 头 13 字节之后是全局色彩表，每个条目 R/G/B 三字节；把每个字节的最低位抽出来连成 bit 流：

- 前 24 bit 是 `MSK`（0x4D 0x53 0x4B）
- 再 8 bit 是长度
- 剩下就是数据

调色板 LSB 隐写。写五行脚本提出 8 字节——第二段 cipher 到手。

这层的 zip 没有任何加密标志，直接解压。

## 4. 第三层：真锁，钥匙挂在锁上

这层解压也弹密码框。熟练地清零 flag——**解压报错**。这层数据是真的 ZipCrypto 加密，不是伪加密。

爆破？不急。这层的 comment 明文可读：

```
MATRYOSHKA-KEY-FRAG 3/5
<16 个 hex 字符>
```

注释写着 KEY 碎片，那……拿它当密码试试？过了。钥匙就挂在锁上。

## 5. 第四层：你来晚啦

这层的 comment 是一段动画——密钥被 kipfel 一口一口吃掉，可见前缀越来越短，最后只剩 `-` 和一串点：

```
你来晚啦，密钥已经被kipfel吃掉一些了>w<
5490d9f>........
5490d9-.........
...
-................
（看起来是空的最后一行）
```

明文永远不完整。但最后一行"空行"有蹊跷：选中复制有内容，hex 查看是一堆 `E2 80 8B / E2 80 8C`——零宽字符 U+200B 和 U+200C。按 ZWSP=0、ZWNJ=1，每 4 个零宽字符转一个 hex 字符，解出 16 字符——和动画里的可见前缀对上了，校验通过。

## 6. 第五层与终点

第五层伪加密都没有，comment 直接给 KEY 碎片。解压出 `END.txt` 和 `prize.png`——到底了。

## 7. 重组：还有最后一坑

集齐 5 段 CIPHER 和 5 段 KEY，按序号拼起来 XOR——乱码。

卡了一会儿，回头想：每段 KEY 是在**层**里拿到的，序号也是层号，但谁说层 i 里放的就是第 i 段 key？试一下倒序：第 1 层的 KEY 不动，其余按 2↔5、3↔4 对调（或者干脆对 5 段穷举排列，用结果可打印性判断）：

```python
cipher = c1 + c2 + c3 + c4 + c5
key    = k(L1) + k(L5) + k(L4) + k(L3) + k(L2)   # 按层收集顺序拼
flag = bytes(a ^ b for a, b in zip(cipher, key))
```

`hctf{...}` 出来了。

## 知识点回顾

1. U+202E RLO 文件名欺骗（显示名 / 真实名 / 真实扩展名三层不一致）
2. 图片尾部追加 polyglot（PNG/GIF 混排，脚本不能写死魔数）
3. ZIP 伪加密 vs 真加密（同弹密码框，判然两物）
4. GIF 全局色彩表 LSB 隐写
5. 零宽字符隐写（ZWSP/ZWNJ 二进制）
6. archive comment 藏数据（密码挂锁上）
7. 碎片倒序配对 + OTP XOR 重组

配套 PoC 见同目录 `exp.py`（支持本地附件或部署 URL）。
