# web_dir_scan

- **分类**：Web
- **难度**：入门
- **题型**：目录扫描 / `robots.txt` 信息泄露
- **附件**：无

## 题面

这是一个"低调"的个人小站。站长说：我的站很干净，首页就那么点东西。

可经验丰富的人都知道——网站真正的秘密，往往藏在能访问、却没人链接的地方。

flag 就在某个你没被告诉过的路径里。拿到它并提交即可。

## 提示

1. 抓站、扫目录是 Web 信息收集的基本功。
2. 搜索引擎不能收录的页面，会写在一个约定俗成的文件里。
3. 404 页面的那句话，其实在暗示你该看哪个文件。
4. 遇到 403 也别急着走，它的存在本身就是情报。

## 部署

```bash
docker build -t web_dir_scan ./src
docker run -d -p 8081:8081 -e FLAG="HCTF{xxx}" web_dir_scan
```

服务监听容器 `8081` 端口，flag 由平台通过 `FLAG` 环境变量注入。
