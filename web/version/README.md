# web_version

- **分类**：Web
- **难度**：中等
- **题型**：`.svn` 源码泄露 + 代码审计（IDOR 越权）+ 命令注入 RCE
- **附件**：无

## 题面

运维小张给内部发布面板做了个"自动同步"功能，说是方便构建机对比线上版本和
代码仓库的差异。他拍着胸脯保证：隐藏目录是白名单开放的，绝对没问题。

面板看起来平平无奇，只有一个登录框。但藏在版本控制元数据里的东西，可不止
登录这么简单。

拿到 flag 提交即可。

## 提示

1. 版本控制留下的痕迹，从不会真正消失。
2. 源码都给你了，就别客气了，挨个文件读一读。
3. 谁是管理员？他的令牌放哪儿了？再有，`tar` 后面拼的东西真的安全吗？

## 部署

```bash
docker build -t version ./src
docker run -d -p 3000:3000 -e FLAG="HCTF{xxx}" version
```

服务监听容器 `3000` 端口，flag 由平台通过 `FLAG` 环境变量注入。
