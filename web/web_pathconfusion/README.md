# web_pathconfusion

- **分类**：Web
- **难度**：简单～中等
- **题型**：剧情向高校统一身份认证平台渗透（Nginx 与后端 URI 解析差异 + 网关路由绕过）
- **附件**：无

## 题面

某高校统一身份认证平台（复刻环境，与任何真实学校无关）。登录页怎么都登不进去——不是让你登进去的。

听说信息中心有个内部接口文档 `doc.html`，但网关直接 403 了。网关就一定靠得住吗？

- flag 形如 `hctf{...}`，位于 `doc.html` 页面中
- 登录接口不是 SQL 注入题，任何账号密码都会返回「用户名或密码错误」

## 部署

```bash
docker build -t pathconfusion ./src
docker run -d -p 58000:80 -e FLAG="hctf{xxx}" pathconfusion
```

- 服务监听容器内 `0.0.0.0:80`（Nginx 网关 + FastAPI 后端同容器），宿主端口 `58000`
- **动态 flag**：平台向容器注入 `FLAG` 环境变量；未注入时使用代码内回退值（保持 `hctf{}` 格式）
- 本题含一个静态诱饵 flag（与真 flag 同为 `hctf{}` 前缀、值不同，判分对比注入值时应判错）
- 本实例为三题赛题链的低难度切片，独立部署、独立可解（链上其余两题的 flag 槽位为无害占位符）
