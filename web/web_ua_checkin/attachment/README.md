# web_ua_checkin 附件说明

本题为白盒 Web 题，附件即全部源码：`index.php`（与部署版本完全一致）。

## 本地运行

需要 PHP 8（无任何扩展依赖，内置开发服务器即可）：

```bash
php -S 127.0.0.1:8080
```

然后浏览器打开 <http://127.0.0.1:8080/>。

## 注意事项

- 服务端按 `User-Agent` 分流：不同客户端/设备看到的响应不同（源码里写得
  很明白，建议用多种客户端访问对比）
- flag 为动态注入：本地不设置 `FLAG` 环境变量时使用代码内回退值，与线上
  环境的 flag 不同；如需模拟线上，可自行设置环境变量后再启动，例如：

  ```bash
  FLAG="hctf{local_test}" php -S 127.0.0.1:8080
  ```
