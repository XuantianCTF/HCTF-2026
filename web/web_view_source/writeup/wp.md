# web_view_source 解题过程

题面：flag 就藏在这个页面里，但页面上永远看不到它。

## 0x00 直接访问

浏览器打开靶机地址，只有一段欢迎文字和"查看源代码"的小课堂提示，
页面上没有 flag。这是刻意设计的：flag 在浏览器不会渲染的区域。

## 0x01 查看网页源代码

用 `Ctrl+U`（macOS：`Cmd+Option+U`）查看网页源代码，或者 `F12` 打开
开发者工具。滚到页面底部，能看到几行 HTML 注释：

```html
<!-- 别往这里看了，flag 不在这行。 -->
<!-- 好吧，你赢了，flag 在这行： -->
<!-- FLAG: HCTF{...} -->
```

`FLAG:` 后面就是 flag。

命令行等价做法：

```bash
curl -s http://HOST:8080/ | grep -i flag
```

## 0x02 小结

| 步骤 | 考点 |
|---|---|
| `Ctrl+U` / `F12` 查看源代码 | 浏览器的"查看源代码"与开发者工具 |
| HTML 注释 | 注释不渲染，但随响应一起下发 |

一键复现见 `exp.py`。
