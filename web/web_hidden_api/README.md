# web_hidden_api

- **分类**：Web
- **难度**：入门
- **题型**：前端源码审计 / 隐藏 API 接口 / base64
- **附件**：无

## 题面

这是一个内部系统的登录页，只有管理员能进。

你手上有浏览器，有开发者工具，你能看到这个系统加载的每一行前端代码。

前端也是代码，前端也藏不住秘密。flag 在一个"不该对外开放"的接口后面。

拿到 flag 提交即可。

## 提示

1. 页面上的东西都可以看，但真正有价值的是它引用的脚本。
2. `F12` → Sources / 网络（Network），看看加载了哪些 `.js`。
3. 前端里硬编码的"调试后门"往往就是出题人留给你的入口。
4. 那串 key 是 base64，解码只是一行命令的事。

## 部署

```bash
docker build -t web_hidden_api ./src
docker run -d -p 8082:8082 -e FLAG="HCTF{xxx}" web_hidden_api
```

服务监听容器 `8082` 端口，flag 由平台通过 `FLAG` 环境变量注入。
