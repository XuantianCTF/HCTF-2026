# web_growcode

- **分类**：Web
- **难度**：入门
- **题型**：动态源码审计 / 命令执行
- **附件**：无

## 题面

队友把他写的小工具源码直接挂在了网页上，还放话："我写的代码就在那儿，多少行都给你看。"

可你总觉得，这文件好像比你上次打开时……长了一点。

## 提示

1. 页面展示的可能只是"当前"的源码——你的操作会带来变化。
2. 被拦截时，看看页面是不是长出了新内容；你的命令被改写时，页面会把改写结果回显给你——新代码和新回显都是提示。
3. 终版代码里，有些变量可以由 POST 替你赋值。

## 部署

```bash
docker build -t web_growcode ./src
docker run -d -p 58002:80 -e FLAG="hctf{xxx}" web_growcode
```

动态 flag：平台启动容器时通过 `FLAG` 环境变量注入；未注入时使用内置兜底值（保持 `hctf{}` 格式，便于本地复现）。flag 不落盘，通关分支直接输出内存中的变量。

## 部署说明（沙箱）

题目含真实命令执行，已做如下隔离，仅供部署者了解，不随题面公开：

- 选手命令统一 `timeout 3` 限时，并经 `su` 降权到 `www-data` 执行，无法读取 root 进程的 `/proc/*/environ`；
- 脚本启动即 `putenv` 清除进程环境中的 `FLAG`，子进程环境与 `/proc` 中均无 flag；
- 源码文件权限 `600`（仅 root 可读），降权后的 shell 无法读取引擎实现；
- PHP 层禁用文件/目录/网络等高危函数（`disable_functions`），并用 `open_basedir=/app` 限制文件访问；
- 回显内容全部经过 HTML 转义，无 XSS。
