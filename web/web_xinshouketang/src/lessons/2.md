# 第二课 · HTTP 响应头

每次打开网页，服务器在送出内容之前，会先递过来一张**看不见的清单**，
列清楚这次返回的状态、类型和一些额外说明——这张清单叫**响应头**（Response Headers）。

浏览器默认不给你看这张清单，但看它的办法很多。
提示、彩蛋、自定义字段，经常就写在响应头里。

## 怎么查看

- 按 `F12` 打开开发者工具，切到「网络 / Network」面板，刷新页面
- 点击第一个请求，找到「响应头 / Response Headers」一栏，逐行读
- 命令行可以用：`curl -I 网址`（`-I` 表示只看响应头）
