# 第五课 · POST 请求

在浏览器地址栏输入网址回车，发出的是 **GET** 请求，意思是「我要看」。
但 HTTP 还有一堆别的请求方法，最常用的是 **POST**，意思是「我要交」——
登录、发帖、提交表单，走的都是 POST。

有些接口只认 POST：用 GET 去敲门，门不会开。

## 怎么发 POST

- 命令行：`curl -X POST 网址`
- 浏览器控制台：`fetch('网址', {method: 'POST'})`
- 也可以用 hackbar 之类的浏览器插件
