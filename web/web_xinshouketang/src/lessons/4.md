# 第四课 · Cookie

Cookie 是网站塞进你浏览器里的**小纸条**。
下次访问时浏览器会自动带上它们，网站靠这个认出你是谁、登录了没有。

既然纸条是塞给你的，你当然有权拆开看。
提示、身份、线索，经常就夹在 Cookie 里。

## 怎么查看

- `F12` 打开开发者工具，「应用 / Application」面板，左侧选「Cookie」
- 或者在控制台（Console）里敲：`document.cookie`
- 命令行可以用 `curl -v 网址`，找 `Set-Cookie` 那一行

## 课后练习

刚才打开这一页时，服务器顺手塞给了你一张纸条。
去 Cookie 里，把它拆开。
